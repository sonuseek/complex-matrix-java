# Лабораторная работа 1: матрицы комплексных чисел

В данной работе реализован класс комплексного числа и методы, которые позволяют
создавать и производить различные арифметические операции с матрицами,
состоящими из комплексных чисел.

## Требования

- Java 17 или выше (проект собран на Java 25)

## Как запустить

Скомпилировать все классы:

    javac Complex.java Matrix.java Main.java

Запустить программу:

    java Main

## Возможности

- Сложение, вычитание, умножение и деление матриц комплексных чисел
- Транспонирование
- Вычисление определителя (метод Гаусса)
- Вычисление обратной матрицы (метод Гаусса-Жордана)
- Деление через умножение на обратную матрицу
- Консольный интерфейс с меню операций

## Структура проекта

- `Complex.java` — класс комплексного числа: поля, конструктор, арифметика, сравнение
- `Matrix.java` — класс матрицы комплексных чисел: хранение, доступ к элементам, все операции
- `Main.java` — консольный интерфейс: ввод матриц, выбор операции, вывод результата
